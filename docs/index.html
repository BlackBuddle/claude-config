Claude Code 작업 흐름을 한 묶음으로

묶음 하나를 고르면, 그 묶음이 끼어드는 단계가 표시됩니다.

설치 3단계 보기 저장소 열기
묶음을 고릅니다
  1. 메시지 입력
  2. 훅 알림여기
  3. 스킬 선택
  4. 하위 에이전트
  5. 검토 제안
2단계 훅 알림. 메시지를 보낼 때마다 실행됩니다. 규칙 4개(선택표, 요약, 검토, 한국어)를 Claude에게 다시 알립니다.
claude/hooks/reminder.txt

setup.ps1로 설치합니다

Windows PowerShell 기준입니다. 처음 1번만 합니다.

  1. 도구를 준비합니다

    Git, GitHub CLI(gh), Claude Code를 설치합니다. 그다음 gh auth login을 실행합니다.

  2. 명령 1줄을 실행합니다

    gh repo clone Dawnilove/claude-config "$env:USERPROFILE\claude-config"; powershell -ExecutionPolicy Bypass -File "$env:USERPROFILE\claude-config\setup.ps1"

  3. 앱을 완전히 종료하고 다시 시작합니다

    Claude Code와 데스크톱 앱 모두 다시 시작합니다. 환경 변수는 새 프로세스부터 적용됩니다.

기존 설정을 덮어쓰지 않습니다

CLAUDE.md
공통 규칙은 CLAUDE.shared.md로 복사합니다. 그 컴퓨터의 파일에는 가져오기 1줄만 추가합니다.
settings.json
훅 1개와 언어 설정만 추가합니다. 고치기 전의 파일은 settings.json.bak-setup으로 남깁니다.
플러그인
이미 설치된 플러그인은 건너뜁니다.
