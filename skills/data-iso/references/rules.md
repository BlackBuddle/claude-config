# 일반 규칙 (data-iso)

anatomy(MIT)의 등각 규칙을 측정 자료 그림에 맞게 옮긴 것이다. 아래 "역할 토큰"은 색의 역할이다. 프로젝트의 색 변수에 대응시킨다 (맨 아래 대응표 예).

## 0. 원칙 4개

SKILL.md와 같다: 지도를 눕힌다 / 닿는 크기 = 자료 크기 / 강조색은 경로와 센서만 / 선은 닿아 끝난다.

## 1. 선

- 물건을 그리는 선은 굵기 1종 0.6 px. 모든 선에 `vector-effect: non-scaling-stroke`. 확대해도 가늘다. 예외는 물건이 아니라 읽는 표지인 것뿐이다: 경로 띠와 남은 길 (5절), 목표 고리 1.2 px, 시작의 가로대 2 px, 끝 점 (길이 0인 4 px 둥근 선), 그림판 테두리 1 px.
- 톤 4개: `hi` 주인공, `mid` 구조(벽·기둥·굵은 눈금), `lo` 바탕·나사·작은 눈금, `faint` 격자·이음선·bevel·홈.
- 좌표는 0.01 px로 맞춘다 (확대하면 0.1 px 계단이 보인다).

## 2. 면 (4톤)

입체 1개를 그리는 순서: 바탕(hull) → 옆면 4톤 → 윗면 → 이음선·bevel·홈 → 테두리.

| 역할 토큰 | 밝은 테마 | 어두운 테마 |
|---|---|---|
| paper (바탕·윗면) | 가장 밝은 면 | 어두운 면 |
| floor (바닥) | paper보다 한 단계 어둡다 | 한 단계 어둡다 |
| shade-3 → shade-0 | 밝은 옆면에서 어두운 옆면 순서로 4단 | 같은 순서 |
| line hi / mid / lo / faint | 짙음 → 연함 4단 | 같다 |
| black body (주인공) | 바닥보다 어둡다 | 바닥보다 더 어둡고 테두리만 밝다 |
| accent / accent-ink / accent-soft | 강조색, 어두운 강조색, 연한 강조색 | 같다 |

- 새 색을 만들지 않는다. 그림자 효과(blur halo)는 쓰지 않는다. 면 음영만 쓴다.
- 어두운 테마 규칙은 우선순위가 낮게 쓴다 (`:where(...)`). 강조색 규칙이 이기게 한다.
- 두 테마 모두 주인공이 가장 어두운 물건이다.

## 3. 구성

- 카메라: 방위·고도는 상수 1쌍. 지도에서 10° 정도만 돌리고 뒤로 눕히면(방위 80°, 고도 42°) 방이 마름모가 되지 않는다. 45° 등각은 방이 마름모가 되어 그림판의 네 귀가 빈다. 원칙 1이 이유다.
- 그림판 = 테두리 1 px의 판. 위 두 귀: 그림 번호, 에피소드 이름. 아래 두 귀: 보기 이름, 읽은 값. 판 밖 아래: 범례와 설명 1줄.
- 글자는 그림 안에 넣지 않는다. 귀의 글자에 대문자 변환·넓은 자간을 쓰지 않는다.
- 그림판 높이는 방의 투영을 따른다. 바닥이 그림판의 약 55 %, 받침판·벽을 더해 약 65 %.
- 받침판: 방 둘레의 턱(0.12 m)과 두께(0.08 m).
- 확대는 나눔 단추 몇 칸 (전체·2배·3배·4배). k배 = 그림판의 1/k 창을 주인공에 둔다. 너무 큰 배율은 방이 안 보인다.
- 잘라 낸 보기: 방 가운데보다 보는 쪽에 있는 벽은 낮은 턱으로 그린다. 안 그러면 방 안이 가려진다.

## 4. 부품 만드는 법

- **받침판**: 턱 → 바닥 → 격자(1 m, `faint`) → 눈금 자(바닥 가장자리에서 턱 쪽으로 자란다. 1칸 = 격자의 1/10, 0.5 m·1 m 눈금은 더 길다) → 네 귀 나사. 두 보기가 같은 함수를 쓴다.
- **기둥**: 받침(반지름 = 자료 반지름, 볼트 8개) → 몸통(74 %, 홈 2줄) → 띠(84 %) → 몸통 → 갓(86 %, 윗면에 고리 2개와 나사). 위에서 본 지도에는 같은 부품의 평면도.
- **벽**: 몸통(자료 크기) + 갓돌(안으로 들임). 보는 쪽 두 면에 1 m마다 이음선. 낮은 턱은 갓돌이 없다.
- **궤도형 로봇**(예): 바닥 = 자료의 로봇 크기. 궤도 2줄 + 몸통 + 위판 + 센서. 그리는 순서는 먼 쪽 → 가까운 쪽. 앞뒤·좌우는 면이 보는 쪽을 향하는지(`facing`)로 정한다. 바퀴에는 살 1줄이 있어야 돈다는 것이 보인다.
- **장애물과 로봇의 앞뒤**: 장애물마다 `g` 1개. 로봇보다 보는 쪽에 있는 장애물을 로봇 다음으로 옮긴다. 한계: 바닥 점 1개의 깊이로 재므로 화면에서 겹치는 장애물 2개 사이에서는 틀릴 수 있다.

## 5. 경로 (시간 자)

경로는 선이 아니라 로봇이 바닥에 깔고 간 자다.

| 부품 | 모양 |
|---|---|
| 띠 | 폭 = 로봇 폭. accent-soft 면 |
| 가장자리 2줄 | accent-ink 0.6 px |
| 1 s 가로대 | accent-ink 1.4 px. 그 순간의 방향에 수직 |
| 가운데 선 | accent 2.2 px |
| 남은 길 | 회색 0.8 px + 짧은 1 s 눈금 |
| 시작 | 로봇의 바닥 윤곽 + 0초의 굵은 가로대 |
| 끝 점 | 길이 0인 선의 둥근 끝 (확대해도 크기 같다) |
| 목표 | 반지름 = 자료의 목표 반지름. 판, 바깥 고리, 안쪽 고리, 십자 눈금 |

- 읽는 법: 가로대 간격 = 속도. 띠가 기둥 받침에 닿으면 로봇이 닿은 것이다.
- 가운데 선과 센서 판에만 accent 본색을 쓴다. 띠와 가로대는 연한 색·어두운 색이다.

## 7. 아우라지 대응표 (예 1개)

| 역할 토큰 | 변수 |
|---|---|
| paper | `--card` |
| floor | `--grid` (어두운 테마 `--hair`) |
| shade-3 / 2 / 1 / 0 | `--field` / `--fill` / `--line` / `--line-strong` |
| line hi / mid | `--sub` / `--gray` |
| black body | `--ink`, 금속 `--sub`, 윗면 `--text` |
| accent | `--accent` / `--accent-ink` / `--accent-soft` |

## 8. 알려진 한계

- 자료의 장면(`scene`)이 없으면 그림판 위가 벽 높이만큼 빈다.
- 전체 보기에서 주인공은 약 20 px다. 세부는 확대에서 보인다.
