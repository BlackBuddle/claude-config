# 움직임 규칙 (data-iso)

움직임은 꾸밈이 아니다. 기록된 자료를 그대로 보인다. 그래서 가감속, 지속 시간(duration), 꾸며낸 진동·흔들림을 쓰지 않는다.

1. **상태에서 계산한다.** 모든 움직임은 지금 시점(슬라이더 위치)의 값에서 나온다. 애니메이션을 "재생"하는 것이 아니다. 슬라이더를 뒤로 끌면 거꾸로 움직인다. 이것이 CSS keyframe을 쓰지 않는 이유다.
2. **바퀴·궤도 무늬는 기록한 이동에서 나온다.** 자세 i−1 → i의 이동 거리 d와 yaw 변화 dθ로 `왼쪽 += d − dθ·W/2`, `오른쪽 += d + dθ·W/2` (W = 로봇 폭, 뒤로 가면 d < 0). 기록을 읽을 때 1번만 계산한다. 바퀴 각 = 거리 / 바퀴 반지름, 궤도 무늬 = `거리 mod 줄 간격`. 제자리 회전에서는 두 쪽이 반대로 돈다.
3. **보간은 재생 중에만.** 위치는 직선, yaw는 가까운 쪽으로, 누적 거리도 직선으로 잇는다. 슬라이더를 끄는 동안에는 잇지 않는다. 멈추면 기록된 자세로 맞춘다.
4. **읽은 값은 기록이다.** 시간·이동 거리·위치·방향 숫자는 내림한 자세(기록된 표본)의 값이다. 보간한 값을 숫자로 보이지 않는다.
5. **`prefers-reduced-motion: reduce`이면** 보간을 끈다 (자세 단위로 넘긴다). 무늬와 바퀴를 세워 둔다.
6. **요소를 다시 쓴다.** 프레임마다 요소를 새로 만들지 않고 있는 요소의 속성(`d`, `class`)만 바꾼다. `style` 속성·`innerHTML`은 쓰지 않는다 (CSP).
7. 확대 전환에는 움직임이 없다 (단추를 누르면 바로 바뀐다).
8. 경로 띠는 슬라이더 위치까지만 깔린다. 앞은 남은 길(회색)이다. 슬라이더에도 같은 1 s 눈금을 단다 (`datalist`, 40개를 넘으면 건너뛴다).
