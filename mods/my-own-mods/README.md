# my-own-mods

릴레이형 작업(설계 → 구현 → 리뷰 → 인계)을 위한 Claude Code 모드, 스킬, 에이전트 모음입니다. 플러그인 3개가 들어 있고, 각각 따로 설치할 수 있습니다.

예전의 `edit-guard`(위험 명령 확인), `agent-panel`(하위 에이전트 패널), `relay-band`(입력창 위 띠)는 `session-board` 안으로 합쳤습니다. 오른쪽 패널을 하나로 쓰고, 띠의 단추가 명령 없이 패널을 열게 하기 위해서입니다.

## 한눈에 보기

| 이름 | 종류 | 나타나는 곳 | 하는 일 |
|---|---|---|---|
| [session-board](plugins/session-board) | 모드 | 오른쪽 패널, 입력창 위 한 줄 | 패널: 세션 상태와 사용자를 기다리는 결재·알림·확인(위), 실행 중인 하위 에이전트(가운데), 위험한 삭제·git 명령의 확인 카드(아래). 띠: 고양이 옆 결재·알림 개수 단추(누르면 패널), 검증 결과, 하위 에이전트 수, 컨텍스트, 주간 한도와 오늘 권장량, 턴 시간, 캐시. |
| [relay-skills](plugins/relay-skills) | 스킬 | 직접 입력할 때만 | `/handoff`: 실행한 명령의 결과를 본 것만 "완료"로 적는 인계 문서(`HANDOFF.md`, 최신 1개). `/recall`: 지난 결정·작업을 결정 기록·HANDOFF·git·세션 기록에서 찾아 출처와 함께 답한다. `/ship`: 커밋·push 직전 점검표(원격 먼저, 비밀 정보, 테스트, 결정 기록, 문서). |
| [relay-agents](plugins/relay-agents) | 에이전트 | 하위 에이전트 호출 | `relay-design`(Opus, high), `relay-build`(Opus, medium), `relay-review`(Opus, high). 모델과 노력 수준이 파일에 고정되어 상한선이 됩니다. |

## 설치

Claude Code 터미널 세션의 입력창에서:

```
/plugin install session-board --marketplace Dawnilove/my-own-mods
```

`y`로 마켓플레이스를 추가한 뒤 범위를 고릅니다. 다른 항목은 이름만 바꿔 같은 방식으로 설치합니다.

설치한 뒤 확인하는 방법:
1. session-board: 세션을 열면 오른쪽에 패널이 열리고 입력창 위에 한 줄 띠가 보입니다. 위험한 삭제 명령을 시키면 패널 아래에 확인 카드가 붙습니다.
2. relay-skills: `/handoff`가 자동 완성에 나옵니다.

## 먼저 알아 둘 것

- 만든 사람의 환경(Windows, Claude Code 데스크톱 앱)에서만 확인했습니다. 다른 환경은 확인하지 못했습니다.
- 위험 명령 확인(옛 `edit-guard`)은 실수로 나가는 명령을 막는 안전장치입니다. 일부러 우회하는 입력을 막는 보안 장치가 아닙니다.
- 비밀 파일 읽기 가드(`secrets.ts`)도 같습니다. Read 도구와 `cat`·`Get-Content` 같은 읽기 명령으로 `.env`, `.credentials.json`, 개인 키를 여는 것을 막습니다. `.example`·`.pub` 파일과 복사·생성은 막지 않습니다.
- 예전에 `edit-guard`, `agent-panel`, `relay-band`를 따로 설치했다면 끄세요. 켜 두면 확인 카드, 에이전트 패널, 띠가 두 번 뜹니다.

## 플러그인별 자세한 설명

<details>
<summary>session-board</summary>

- 세션마다 칸 하나: 고양이, `● 작업 중 · 1분 15초` 머리글, 세션 이름(앱 사이드바 제목). 색은 앱 테마를 따라갑니다.
- 결재(빨강)·알림(노랑)·확인(초록): 세션 답의 `결재:`·`알림:`·`확인:` 줄, 선택 카드, 질문 상자, 물음표로 끝나는 마지막 줄에서 뽑습니다.
- 이름을 누르면 질문·배경·선택지가 펴지고 `이동` 버튼으로 그 세션에 갑니다. 펼칠 것이 없는 세션은 누르면 바로 갑니다.
- 닫기: 알림은 언제나, 결재는 세션이 끝났거나 24시간이 지났을 때만. 확인은 `확인` 버튼으로 닫습니다.
- 같은 프로젝트의 다른 세션에 새 결재·알림이 오면 토스트를 띄우고 패널을 엽니다.
- 위험 명령 확인: `sed -i`, heredoc 쓰기, 문자열 치환 같은 파일 훼손 명령은 한국어 사유로 막습니다. `rm -rf`, `git reset --hard`, 강제 푸시, `Remove-Item -Recurse`는 영향 범위를 보여주고 진행/취소를 묻습니다(단축키 `1` 취소, `2` 진행). 영향 범위 계산에는 `bash`와 `git`이 필요합니다.
- 하위 에이전트: 실행 중인 에이전트가 위에 오고, 이름·유형·호출 수·마지막 도구를 보여줍니다.

</details>

<details>
<summary>session-board의 입력창 위 띠 (옛 relay-band)</summary>

- 맨 왼쪽 고양이 옆에 결재·알림·확인 개수를 색 점과 숫자로 보여 줍니다(빨강 결재, 노랑 알림, 초록 확인). 누르면 세션 보드 패널이 열립니다.
- 컨텍스트와 주간 한도는 색 게이지(▰▱)로, 이상 값과 검증 결과는 색 알약으로 보여 줍니다.
- 폭이 좁으면 중요도가 낮은 칸부터 숨깁니다. 이상이 생긴 칸(주의·위험)은 마지막까지 남깁니다.
- 줄 오른쪽 끝의 `상세 ▾`를 누르면 컨텍스트 토큰 수, 주간 한도 리셋, 오늘 권장 계산, 캐시 만료 같은 근거와 날씨 기호의 뜻이 펼쳐집니다.
- 입력창 위 띠 자리를 [ponytail](https://github.com/DietrichGebert/ponytail)의 띠와 나눠 씁니다. 그 띠 아래에 붙고, 데스크톱 화면에서는 줄을 맞추려고 1칸 들여씁니다(코드 맨 위의 `INDENT`).
- 비용 칸은 ponytail이 이미 보여줘서 기본으로 숨깁니다(`SHOW_COST`).
- 주간 한도 칸은 계정이 `seven_day` 한도 값을 줄 때만 나옵니다.

</details>
