# humanizer-ko

[blader/humanizer](https://github.com/blader/humanizer)의 한국어 판이다. 2026-11-18 사용자 결정: "포크해 한국어로 개조".

- 원본: 4.0.0, 커밋 `b48c832`. 라이선스 MIT (`LICENSE`는 원본 그대로).
- 쓰는 곳: 사람에게 보일 한국어 글 (블로그, 자기소개서, 보고서, 발표문, README, 메일).
- 쓰지 않는 곳: Claude의 답변 문체. 답변은 전역 규칙의 STE 문체를 따른다.
- 부르는 법: `/humanizer-ko`, 또는 "AI 같은 글투를 고쳐 줘", "사람이 쓴 것처럼 다듬어 줘".

## 원본에서 바꾼 것

| 원본 | 한국어 판 | 이유 |
|---|---|---|
| 영어 예문 전체 | 한국어 예문으로 다시 씀 | 한국어 글에 쓴다 |
| 7. 같은 주어(she/he) 반복 | 7. 같은 어미·같은 첫머리 반복 ("~습니다.", "이를 통해") | 한국어 AI 글에서 가장 눈에 띄는 리듬 |
| 10. 하이픈 복합어 | 10. 번역투 ("~에 있어서", "~하는 것이 중요합니다") | 하이픈은 영어에만 있다 |
| 11. 피동 | 11. 피동과 "~되어지다" | 한국어 이중 피동 추가 |
| 12. AI 영어 낱말 (delve, tapestry…) | 12. AI 한국어 낱말 (다양한, 도모하다, 극대화…) | 낱말 목록은 언어마다 다르다 |
| 18. is/are/has 피하기 | 18. "이다·있다" 피하기 (~로서의 역할을 하다, ~를 자랑한다) | 같은 현상의 한국어 모습 |
| 21. 둥근 따옴표 | 21. 지나친 존댓말 (~해 드리겠습니다) | 둥근 따옴표는 한국어 글의 신호가 아니다 |
| 나머지 1~6, 8, 9, 13~17, 19, 20, 22~26 | 구조와 규칙은 그대로, 찾을 표현과 예문만 한국어로 | 언어와 상관없는 패턴 |
| description | 한국어, 답변 문체에는 쓰지 않는다고 명시 | STE 규칙과 충돌을 막는다 |

## 원본이 바뀌면

```powershell
git clone --depth 1 https://github.com/blader/humanizer.git $env:TEMP\hu
git -C $env:TEMP\hu log --oneline b48c832..HEAD -- SKILL.md
```

새 패턴이 언어와 상관없으면 한국어로 옮겨 넣는다. 그 뒤 이 파일과 `plugin.json`의 커밋 해시를 고친다.
